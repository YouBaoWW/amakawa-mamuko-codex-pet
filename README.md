# 天川真梦梓 · Codex 宠物


## 内容

- Codex v2：8 列 × 11 行，1536 × 2288 像素，每帧 192 × 208。
- 9 组标准动画：待机、向右移动、向左移动、挥手、跳跃、失落、等待输入、工作、审阅。
- 16 个顺时针视线方向：正上方起，每隔 22.5° 一帧；包含正下、正左、正右。
- 透明 WebP 图集与 `spriteVersionNumber: 2` 配置。

## 安装

将包内 `amakawa-mamuko` 文件夹放到当前用户的 `.codex/pets/` 下，保持 `pet.json` 和 `spritesheet.webp` 同层。完成后从 Codex 的宠物选择入口选择“天川真梦梓”。如果列表尚未刷新，重新打开 Codex 后再查看。
