## 安装文件

ZIP 只包含 `pet.json` 和 `spritesheet.webp`。将两个文件放进当前用户的 `.codex/pets/amakawa-mamuko/`，保持同层。

```text
.codex/pets/amakawa-mamuko/
├── pet.json
└── spritesheet.webp
```

显示名为「天川真梦梓」，ID 为 `amakawa-mamuko`。本目录中的 README 和 GIF 用于说明与预览，安装只需要上述两个文件。

## 图集

透明 WebP，1536 × 2288 像素，8 列 × 11 行，单帧 192 × 208。包含 9 组标准动画、独立中立帧及 16 个顺时针视线方向。

下载整个仓库并打开根目录的 [preview.html](../preview.html)，即可切换本款的动作和视线方向。GIF 是从原图集提取的展示预览；实际播放节奏由应用控制。
